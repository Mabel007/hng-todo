# HNG Todo

A polished, responsive Todo application for managing everyday tasks with a calm, local-first experience.

## Features

- Create, edit, delete, and complete tasks
- Filter tasks by All, Active, or Completed
- Search tasks by title
- Persist tasks in browser `localStorage`
- Clear completed tasks
- Responsive mobile and desktop layouts
- Accessible labels, keyboard interactions, and visible focus states
- Helpful empty states for filtered and searched lists

## Tech stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Browser `localStorage` for persistence

## Local setup

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

To validate the project:

```bash
npm run lint
npm run build
```
